# BeebPab

แอป Mac สำหรับย่อภาพก่อนโพสต์ Facebook หรือส่ง LINE ให้ภาพยังคมชัด
ภาพถูกย่อให้ตรงกับขนาดที่แพลตฟอร์มใช้พอดี แพลตฟอร์มจึงไม่ต้องย่อหรือบีบอัดซ้ำ

## วิธีใช้
1. ลากรูปภาพหรือโฟลเดอร์มาวาง (หรือกด ⌘O)
2. เลือกเป้าหมาย เช่น Facebook โพสต์ทั่วไป หรือ LINE แบบ HD
3. เลือกโฟลเดอร์บันทึก แล้วกด "ย่อภาพ" (⌘↩)

## เปิดโปรเจกต์
```bash
xcodegen generate   # สร้าง BeebPab.xcodeproj จาก project.yml
open BeebPab.xcodeproj
```

## ขนาดภาพอัปเดตอัตโนมัติ
- ค่าทั้งหมดอยู่ใน `presets/presets.json` ไฟล์เดียว ไฟล์นี้ฝังในแอปด้วย
- แอปโหลดไฟล์ฉบับล่าสุดจาก GitHub ทุก 24 ชม. ตั้งที่อยู่ไฟล์ใน `BeebPab/App/AppConfig.swift`
- `.github/workflows/check-specs.yml` ตรวจหน้าข้อมูลทางการ (ช่อง `source`) ทุกวันจันทร์ ถ้าตัวเลขเปลี่ยน
  จะเปิด Issue แจ้ง แก้ `presets.json` แล้วเปลี่ยน `updatedAt` แอปทุกเครื่องจะได้ค่าใหม่เอง
